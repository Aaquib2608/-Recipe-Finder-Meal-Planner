# Recipe-Finder-Meal-Planner

README for running and understanding this project.

## Setup Instructions

1. Install Node.js (recommended: latest LTS).
2. Install dependencies:

```sh
npm install
```

3. Optional checks:

```sh
npm run check
npm run lint
```

## Assumptions Made

- Node.js and npm are already installed on your machine.
- This project uses the existing scripts in package.json (vite + svelte-kit).
- Deployment target is GitHub Pages for this repository.

## Starting Development Server

Run:

```sh
npm run dev
```

Open the local URL shown in your terminal (typically http://localhost:5173).
